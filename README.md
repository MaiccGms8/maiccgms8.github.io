## 🗂️ Estrutura do Projeto

O site é uma aplicação web estática (*Static Site*) construída com as tecnologias base da web, focada em leveza, alta performance e design responsivo moderno:

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Variáveis nativas, design escuro (*Dark Mode*) e estilização responsiva sem dependência de frameworks.
- **JavaScript (Vanilla):** Navegação entre abas, sistema de filtragem dinâmica do portfólio e interatividade da barra lateral.
